# D10 — Sandbox isolation

**Status:** PASS (2026-08-31) — verify cycle 0; 19/19; next orchestrator advance  
**Wave:** 4 (after D1 auth, D6 file tools + SandboxPolicy, D9 TreeIO/durable cache contract; with D5 env/VK hygiene; grants in D11)  
**Depends on:** D1 (tenant + no secrets in agent), D5 (`sanitize_sandbox_env` + VK-only credentials), D6 (`file_effects` gate), D9 (`as_tree_io` + hydrate/sync on non-local), D11 (`sandbox:exec` durable)  
**Goal:** Agent code and tools run in an isolated compute boundary. Deploy and composition pins agree on provider. Docker/E2B support TreeIO so D9 hydrate/sync works. Network/CPU/mem hardened. Host providers forbidden under `MULTI_TENANT_STRICT`. Secrets and vendor keys never enter sandbox env.

**Done means (north star):**

> A `requires_sandbox` session on staging uses `local_docker` or `e2b` (not bare host). Scoped hydrate/sync succeeds via provider TreeIO. Env scrub applies on every provider. Policy `file_effects` still gates tools. Multi-tenant strict refuses `local_process` / `local_docker`. Sandbox remains a **cache** (D9) — never the durable SoT and never the grant authority (D11).

## 1. Why D10 exists

D6/D9 make `/workspace` tools and dual-SoT real on `local_process`. Without D10, “sandbox” is a host tempdir or an unhardened container:

```text
SANDBOX_PROVIDER / SandboxProfile.provider
        │
        ▼
sandbox/factory.py  (sole name → impl)
        │
        ├── none           → no-op (kg-v1 style)
        ├── local_process  → host dir + subprocess + TreeIO   ← only full FS path today
        ├── local_docker   → container create/exec/destroy    ← no TreeIO / no scrub
        └── e2b            → remote SDK                       ← no TreeIO / no scrub

Control plane (not inside sandbox):
  SandboxPolicy.file_effects     → D6
  approval_default               → D8
  authorized hydrate/sync        → D9 + D11
  sanitize_sandbox_env           → D5 / D10 (must be universal)
```

Until D10 closes:


| Today                                           | Problem                                                          |
| ----------------------------------------------- | ---------------------------------------------------------------- |
| Default `SANDBOX_PROVIDER`                      | `none`                                                           |
| Only TreeIO path                                | `local_process` — no OS isolation                                |
| `local_docker` / `e2b`                          | Lifecycle real; **no** `as_tree_io` → `WorkspaceSyncUnsupported` |
| Env scrub                                       | `local_process` **only**                                         |
| Docker create                                   | No mem/CPU/network/cap hardening in code                         |
| Githi YAML `allow_network` / `allow_subprocess` | Declared; **not enforced** by providers                          |
| `local_process.destroy`                         | **No-op** — disk leak                                            |
| Outer FE/BE                                     | No sandbox UX                                                    |
| Plan doc “GcpSandbox”                           | **Not in code**; E2B is the multi-tenant path today              |


**UI surfaces that depend on D10**

## 2. Architecture rules (freeze)

1. **Factory is the only name → impl map** (`sandbox/factory.py`, `contracts/sandbox_profile.md`).
2. **Composition** `SandboxProfile` **overrides deploy** `SANDBOX_PROVIDER` when pinned; fail loud on `requires_sandbox` mismatches.
3. **Sandbox = hot cache** (D9) — never durable SoT; never grant authority (D11).
4. **Do not redefine** `file_effects` **/** `approval_default` — those are D6/D8; isolation must honor the same gates.
5. `sanitize_sandbox_env` **on every provider** that accepts env — deny vendor keys, `GATEWAY_TOKEN`, DB URLs, etc. (D5).
6. **Vendor / gateway secrets never in sandbox** — session may receive `vk_` **only** if the agent must call the gateway.
7. `MULTI_TENANT_STRICT=true` → forbid `local_process` and `local_docker`; allow `e2b` **or** `none`.
8. **Hydrator has no GrantStore** — façades only adapt FS → `WorkspaceTreeIO`.
9. **Image identity** — pin `image_digest` (profile or harness); do not float `latest` in staging.
10. **Network default-deny** in production (K8s NetworkPolicy template exists) — allow only what tools need (e.g. DNS + gateway).
11. **Browser never talks to Docker/E2B** — control plane via supervisor/BFF (D1).
12. **GcpSandbox / GKE workers** (plan Phases 12–14) = future provider behind the same ABC — do not fork a second sandbox API.
13. **Harness YAML** `sandbox.allow_`* is advisory until providers enforce; profile + NetworkPolicy are the production controls.

## 6. Implementation order

1. **Universal** `sanitize_sandbox_env` on docker/e2b create + spawn/exec.
2. **Fix docker path injection** (`exists` / exec quoting).
3. **TreeIO for** `local_docker` — volume or archive push/pull mapped to `WorkspaceTreeIO`; wire hydrator in factory.
4. **Docker hardening** — mem/CPU, `cap_drop`, network mode / CNI + apply NetworkPolicy template in deploy docs.
5. **E2B TreeIO** — SDK filesystem ↔ TreeIO; hydrate/sync.
6. `local_process.destroy` cleanup + idle reap defaults for staging.
7. **Staging compose** — explicit `SANDBOX_PROVIDER`; document MT strict + e2b for shared.
8. **Ready probe (D2)** — optional sandbox ping when provider ≠ none.
9. **Catalog seeds** — `sandbox_profiles/*.json` for coding/githi.
10. **GcpSandbox** (later) — same Protocol; GKE worker pool from plan.

Do **not** redefine dual-SoT or `file_effects`. Do **not** put grant checks inside the container.

## 9. Definition of done

D10 is **done** when:

1. Staging coding/githi runs on **isolated** providers (docker and/or e2b), not bare host as the default story.
2. Those providers support **TreeIO hydrate/sync** (D9 path works).
3. **Env scrub is universal**; no vendor/gateway secrets in sandbox.
4. **Resource/network** controls exist for docker (and documented for e2b).
5. `MULTI_TENANT_STRICT` is tested and used for shared deploys.
6. Policy / approvals / dual-SoT ownership stays with D6/D8/D9 — isolation only.

Then proceed to **D11** (durable grants) and **D12** (subagents / HA), without re-litigating “what a sandbox is.”

## 10. Key paths + quotes



### Factory (sole name map)

```11:40:services/supervisor/src/supervisor/sandbox/factory.py
def create_sandbox_provider(
    name: str | None = None,
    *,
    client: object | None = None,
    hydrator: WorkspaceHydrator | None = None,
) -> SandboxProvider:
    """Select provider from ``SANDBOX_PROVIDER`` or an explicit name.

    Names: ``none`` | ``local_process`` | ``local_docker`` | ``e2b``

    ``hydrator`` is forwarded to ``local_process`` (WP-M3). Other providers
    ignore it until docker/E2B TreeIO adapters exist.
    """
    chosen = (name or os.environ.get("SANDBOX_PROVIDER") or "none").strip().lower()
    if chosen in ("none", "null", ""):
        return NoneProvider()
    if chosen == "local_process":
        from supervisor.sandbox.local_process import LocalProcessProvider

        return LocalProcessProvider(hydrator=hydrator)
    if chosen == "local_docker":
        from supervisor.sandbox.local_docker import LocalDockerProvider

        return LocalDockerProvider(client=client)
    if chosen == "e2b":
        from supervisor.sandbox.e2b import E2BProvider

        return E2BProvider(client=client)
    raise ValueError(f"unknown SANDBOX_PROVIDER={chosen!r}")
```



### Multi-tenant gate

```6:17:services/supervisor/src/supervisor/sandbox/gate.py
def assert_multi_tenant_sandbox_provider(
    provider_name: str,
    *,
    multi_tenant_strict: bool,
) -> None:
    if not multi_tenant_strict:
        return
    name = provider_name.strip().lower()
    if name in ("local_docker", "local_process"):
        raise ValueError(
            f"{name!r} is not permitted when MULTI_TENANT_STRICT=true; use e2b or none"
        )
```
