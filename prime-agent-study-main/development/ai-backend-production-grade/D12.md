## 2. Architecture rules (freeze)



### Subagents

1. **Supervisor observes children via journal + commands** — never import harness/Cordis child types into `session/` / `journal/` / `api/` (`contracts/subagent.md`).
2. **Factory/binders own concretes** — `SubagentOps` takes `SubagentTransport` Protocol only (P-3).
3. `MemorySubagentProvider` **≠ LTM** — provider name `"memory"` is an in-process **echo stub**; ContextMemory / Durable Memory are D7. Never conflate in docs or UI.
4. **Journal Start before provider work** for spawn/fork; unpaired start → recovery like unpaired tools.
5. **Continuable requires method presence**, not only a capability string.
6. **Composition** `acp_base_url` **overrides** env `ACP_BASE_URL`.
7. **Depth is enforced** — harness `subagents.max_depth` must gate spawn (not advisory).
8. **Browser never calls supervisor child APIs** — BFF + service cred (D1).
9. **Child auth** — same tenant/session access as parent; no anonymous ACP in staging.



### High availability

1. **Cold resume = journal SoT** — shared Postgres allows peer to continue without warm runtime.
2. **Warm path needs ownership** — LiveHub, runtime registry, sandboxes, `respond_ui`, in-process subagent handles are **not** multi-writer.
3. **Policy before scale** — either `replicas=1` for warm sticky sessions, **sticky LB by** `session_id`, or **shared live bus + runtime lease**. Silent round-robin is forbidden for warm Test chat.
4. **Drain must refuse mutating APIs** — not only create (D2/D4 leftover).
5. **Durable deps before multi-tenant HA** — VK (D5), workspace (D9), grants (D11); else replicas invent divergent worlds.
6. **Approval** `expire_due` **needs a leader lease** under multi-replica (D8).
7. **Rate limits** — in-process limiter × N replicas; move to Redis/edge if scaled.
8. **Gateway HA** — single process until VK store is durable.

## 5. Acceptance criteria



### A. Subagents (execution)

- [ ] Production default provider is **not** echo `"memory"` (ACP, nested session, or explicit lab-only flag)
- [ ] Spawn/fork: paired journal events; HTTP returns **same** `child_id` / `run_id` as journal
- [ ] Background: `JobEnd` + `SubagentEnd` on completion/failure/cancel
- [ ] Continuable either implemented or removed from product API until ready
- [ ] `max_depth` enforced; over-depth → 400 with clear code
- [ ] ACP client uses service auth (D1); initialize fails loud in staging
- [ ] Unpaired starts → recovery `NEEDS_REVIEW`



### B. Subagents (product) + local demo ([LOCAL_DEMO.md](./LOCAL_DEMO.md) #4)

- [ ] BFF proxies spawn + list children (+ SSE chips via D4)
- [ ] Outer `/subagents` uses **live** data (not mock); nav entry present or linked from Test  
- [ ] Naming: never label the `"memory"` provider as long-term memory
- [ ] **Local demo:** spawn one child from Test or Subagents UI; see `subagent_`* chips in chat/Traces  
- [ ] Echo provider only as `lab_echo` with badge — unmarked Done forbidden  
- [ ] “Disabled with honest copy” may PASS HA-only slices; it **FAILS** local-demo gate  



### C. HA policy

- [ ] Documented deploy mode: `replicas=1` **or** sticky by `session_id` **or** shared live bus
- [ ] **Local demo:** `replicas=1` is enough (sticky LB not required on laptop)  
- [ ] Staging compose matches the chosen mode (LB sticky header/cookie if sticky)
- [ ] Cold resume proven: kill owner pod → peer continues from journal (message works; live may replay)
- [ ] Wrong-replica warm `respond_ui`: either routes to owner or queues for owner (no silent skip)
- [ ] Drain: message/fork/abort refuse while draining; `/readyz` 503
- [ ] Approval sweeper single-leader (lease) if multi-replica
- [ ] Rate limit shared or edge-enforced if multi-replica
- [ ] Gateway remains single until durable VK (D5)



### D. Explicitly out / later

- [ ] Full Cordis/harness-in-process child graph inside supervisor  
- [ ] Multi-region active-active without ownership protocol  
- [ ] Composition `subagent_bindings` rich product (can follow once spawn is real)

## 6. Implementation order

1. **HA policy doc + staging** — pick sticky vs replicas=1; add LB sticky if needed; close drain mutating gates.
2. **ID + response hygiene** — align journal/provider/HTTP `child_id`/`run_id`.
3. **Background job completion** — pair ends; optional job_list/kill.
4. **Depth enforcement** from harness/composition.
5. **Real child provider** — nested session spawn **or** hardened ACP (auth, no soft-fail init); quarantine echo as `lab_echo` / tests-only.
6. **Sticky** `respond_ui` **+ sweeper lease** (with D8).
7. **Shared live bus (optional)** — only if sticky LB insufficient.
8. **BFF + FE** — sessions/SSE/subagents; kill mocks.
9. **Prerequisite stores** — ensure D5/D9/D11 not memory before multi-tenant multi-replica.

Do **not** scale warm replicas on round-robin. Do **not** ship Subagents UI on echo provider without a lab badge.

## 9. Definition of done

D12 is **done** when:

1. Child spawn in staging is a **real** provider path (not unmarked echo).
2. Journal pairing, depth, and ID alignment hold under tests.
3. HA mode is **chosen and enforced** in staging (sticky, bus, or single replica).
4. Warm HITL (`respond_ui`) and live SSE behave correctly under that mode.
5. Drain + sweeper are multi-replica safe.
6. Outer Subagents UX is **honest**.
7. Series D1–D12 prerequisites for “production-shaped AI plane” are named; remaining work is implementation, not unknown dimensions.
