# D7 — Memory (compaction + durable LTM)

**Status:** Contracts + seams + standalone Memory Service real; product turn path incomplete; outer Memory UI mock  
**Wave:** 2–3 (after D1 auth, D2 ready policy, D3 memory_profile pin, D4 journal/SSE; parallelizable with D5/D6 once auth+ready exist)  
**Depends on:** D1 (service auth + tenant-bound memory), D2 (`memory` in platform status / Run gate policy), D3 (pinned `MemoryProfile` digests), D4 (`compaction_*` / `memory_recall` on journal + SSE), D5 (summarization model for compaction), D6 (optional `remember` tool in ToolSet)  
**Goal:** Session context compaction is reliable and journaled. Durable long-term memory (Tier 1 log + Tier 2 bank) is deployed, authenticated, tenant-safe, and reachable from the agent turn (recall inject + write). Outer product Memory UX maps honestly to AI scopes/items — or is labeled “not wired” until a BFF exists.

**Done means (north star):**

> A composition-pinned session can compact under pressure with paired journal events, recall durable facts into context when the profile enables it, and write facts via a ToolSet tool (or extraction) into a tenant-scoped bank. Memory Service is in compose with auth + `/readyz`. Browser never talks to memory; BFF never invents a parallel “store library” that disagrees with AI scopes.

## 2. Architecture rules (freeze)

1. **Two capabilities, two contracts** — do not merge:
   - **ContextMemory** (`contracts/memory.md`) = compaction + optional semantic inject for the **live session**.
   - **Durable Memory** (`contracts/durable_memory.md`) = Tier 1 transcript log + Tier 2 semantic bank, **agent-independent** sibling service.
2. **Dual log (ADR-001)** — supervisor journal = control-plane recovery; Memory Tier 1 = harness-neutral `SessionEvent` transcript. Do not treat one as the other.
3. **Outbox ownership (ADR-004)** — supervisor `tool_outbox` for `invoke_tool`; Memory `outbox` for Tier 1 `tool/call` + `side_effect`. **Never cross-wire.**
4. **Browser never calls Memory Service or supervisor memory RPC** — system BFF + service cred (D1).
5. **Tenant is cryptographically bound** (D1) — Memory must not trust client-asserted `scope.tenant` alone; fix IDOR on `GET /v1/memory/items/{id}`.
6. **Composition pin is source of truth for ContextMemory** — `MemoryProfile` digests via D3; harness YAML `memory:` flags are **recovery / Phase flags**, not the runtime profile.
7. **Recall fail-soft** — `MemoryOps.recall` journals `memory_recall` and **must not fail the run** (`contracts/memory.md`).
8. **Compaction pairing** — unpaired `compaction_start` → same recovery class as unpaired `tool_start` (D4).
9. **`MemorySubagentProvider` ≠ LTM** — in-process subagent stub named `"memory"`; never document as semantic memory.
10. **Outer “memory stores” (doc/web/DB)** are a **different product metaphor** — map to AI `Scope{tenant,subject,namespace}` + items, or keep UI disabled with the harness 422 honesty.
11. **Default Memory listen port must not collide with gateway** — prefer **8091** (or remap); document in compose (D2 leftover).
12. **Vendor embeddings / summarizers** stay behind gateway (D5) — Memory hashing stub is lab-only until a real embedder is configured.

## 5. Acceptance criteria

### A. Deploy + trust (with D1/D2)

- [ ] Memory Service in staging compose on **non-colliding port** (e.g. 8091) with healthcheck
- [ ] Service credential required on all mutating/reading routes (fail-closed in staging)
- [ ] Tenant from verified claims; `GET item` cannot cross tenant (404/403)
- [ ] `/v1/readyz` reflects DB readiness; platform status includes `memory` when policy requires it
- [ ] `MEMORY_SERVICE_URL` set for harness bind; supervisor materializes `memory_service.json`

### B. ContextMemory (session)

- [ ] Pinned profile with compaction on: pressure/manual compact journals paired `compaction_start`/`end`
- [ ] Unpaired start → recovery `NEEDS_REVIEW`
- [ ] Recall-enabled profile: `memory_recall` appears on SSE; run continues if recall empty/fails
- [ ] No profile pin → Null provider; compact/recall RPC fail loud (configured vs missing)

### C. Durable LTM during a turn

- [ ] Enabled profile (or ToolSet) can **recall** Tier 2 into context for a prompt
- [ ] Agent (or extraction) can **write** a fact to Tier 2 with scope = session tenant/subject/namespace
- [ ] Write path uses Memory outbox rules where side effects apply; supervisor tool invoke stays on supervisor outbox
- [ ] Forget / erase_subject audited; product privacy path documented

### D. Outer product honesty

- [ ] Either: BFF proxies list/search/forget to durable APIs with ownership, FE drops mocks  
- [ ] Or: Memory nav/harness attach stay disabled with same 422 message until BFF ships  
- [ ] No third metaphor (mock “document stores”) pretending to be live

### E. Quality floor (lab→staging)

- [ ] Documented embedder: hashing OK for CI; real embedder or explicit “lab-only” flag for staging demos
- [ ] Extraction worker or cron drains queue in staging (not manual-only)

## 6. Implementation order

1. **Port + compose + Dockerfile** — Memory on 8091; `MEMORY_SERVICE_URL` on supervisor/harness; D2 healthchecks.  
2. **Auth + tenant bind (D1)** — Bearer service token; fix item GET IDOR; optional RLS later.  
3. **`/v1/readyz` + platform probe (D2)** — policy: required vs soft-degraded for Run.  
4. **Enable recall path** — MemoryProfile with `recall.enabled` + backend that hits durable `/v1/memory/recall` (or MCP `memory_search` that does). Wire Pi hooks.  
5. **Agent write** — add `remember` (or catalog tool) → durable write; pin in ToolSet (D6/D3). Journal observability as needed.  
6. **Durable Pi Tier 2 client** — items + recall methods; keep Tier 1 flush rules.  
7. **Extraction worker** — process jobs continuously in staging.  
8. **Outer BFF (optional wave)** — map product Memory UX to scope/items/recall/forget **or** keep blocked.  
9. **Embeddings upgrade** — replace hashing when retrieval must be demo-quality; pgvector optional later.  
10. **Retention / hard delete** — product decision + API; archive backend beyond local FS.

Do **not** start with outer mock redesign or pgvector before auth, deploy, and turn R/W glue.

## 9. Definition of done

D7 is **done** when:

1. Durable Memory is **deployed**, **authenticated**, and **tenant-safe** in staging.  
2. ContextMemory compaction works on pinned profiles with **paired journal/SSE** events.  
3. An agent turn can **read and write** long-term facts (profile/tool path) against the durable bank — not only compaction.  
4. ADR-001 / ADR-004 boundaries hold under tests.  
5. Outer Memory UI is **honest** (wired BFF or explicitly unavailable).  
6. D1/D2 memory rows (auth, readyz, port) are closed or explicitly deferred with dates.

Then proceed to **D8** (approvals + budgets), **D9** (workspace), etc., without re-litigating “what memory means.”
