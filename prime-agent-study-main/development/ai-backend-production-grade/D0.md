# D0 — Verification loop (no MVP)

**Status:** Protocol — required for every Dn and SESSION-AT-SCALE / tracing work  
**Wave:** −1 (before D1; runs continuously through D13)  
**Goal:** Nothing is “done” because a human or agent *claims* it. Done means a **fresh verify subagent** scores the tree against the guide’s acceptance criteria and returns **PASS** with no open P0/P1 gaps for that scope.

**Done means (north star):**

> For the active Dn (or scoped slice): Implement → Verify(subagent) → if FAIL, implement only reported gaps → Verify again → until PASS. No MVP waivers unless explicitly dated and listed as residual risk.

**Series end-state (second north star):**

> After D1–D13, [LOCAL_DEMO.md](./LOCAL_DEMO.md) must PASS: laptop compose + harness + custom tool + subagent + workspace upload + chat against that workspace + session traces. Per-Dn PASS with mock FE or “not shipped” on those surfaces is **not** series Done.

---



## 1. Loop (normative)

```text
┌─────────────────────────────────────────────┐
│  1. SCOPE     Pick Dn + acceptance rows     │
│  2. IMPLEMENT Change code/config/tests      │
│  3. VERIFY    Spawn subagent (fresh)        │
│               Score vs Dn acceptance only   │
│  4. DECIDE    PASS → stop / next Dn         │
│               FAIL → go to 2 with gap list  │
└─────────────────────────────────────────────┘
```

Rules:

1. **Verify agent does not implement** — report only (status, evidence paths, missing rows).
2. **Implement agent does not self-certify** — must call verify after material changes.
3. **No MVP** — do not mark acceptance `[x]` while verify still lists that row as missing/partial.
4. **Evidence required** — verify cites files, tests, env, or command output; no vibes.
5. **Regressions count** — if verify finds a previously green Dn broken, FAIL and fix before continuing.
6. **Outer BFF/FE** — when Dn acceptance requires product honesty, verify includes `backend/prime_agent` and `frontend` as in scope.

```text
## Regressions (if any)
## Suggested next implement slice (max 5 bullets)

Be strict. Stub/env-default-unsafe = not green. "Code exists but compose defaults memory" = partial at best.
```

## 3. Implement slice rules

After FAIL:

1. Implement **only** the verify gap list (highest severity first).
2. Add/adjust tests that would have caught the gap.
3. Re-run local tests for touched packages when feasible.
4. Spawn a **new** verify subagent (do not reuse the implementer’s context as proof).

Stop conditions:

- **PASS** on scoped acceptance → record in Dn status line + date; proceed to next Dn or next scope.  
- **Blocked** (external secret, product decision) → write residual with owner + date; do not pretend PASS.
