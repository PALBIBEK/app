# D4 — Sessions + SSE traces

**Status:** PASS (2026-08-30) — verify cycle 1 scored 34/34; next scope D5  
**Wave:** 1 (after D1 auth, D2 ready gates, D3 catalog/harness bind)  
**Depends on:** D1 (`AiClient` + service credentials), D2 (`run_allowed` / platform status), D3 (stored `harness_version` + composition digest pins)  
**Goal:** Product Test chat, Sessions, Traces, and Stop talk to the real supervisor session lifecycle over the system BFF — create/list/get/message/abort/terminate/fork, durable journal, resumable SSE — never mock chat and never browser→supervisor.

**Done means (north star):**

> BFF creates a session with D3 pins only, streams journal/live events as SSE to the UI, stops in-flight work via abort, and lists reconstructible session history. Digests stay immutable; `command_id` makes message POST idempotent; `Last-Event-ID` resumes without gaps/dupes on a single supervisor instance.

## 1. Why D4 exists

D1–D3 make the AI plane *callable*, *gated*, and *pinnable*. D4 is the first product loop that uses them:

```text
UI Test / Sessions / Traces / Stop
  → System BFF (user JWT, D2 run_allowed, D3 pins)
  → AiClient + service credential
  → Supervisor /v1/sessions* + SSE /events
  → Journal (truth) + LiveHub (hot tail) + runtime fan-out
```

Until D4 closes:

| Today | Problem |
|-------|---------|
| UI Test | Mock / fake success (or disabled without a real BFF) |
| Sessions list | No tenant-bound AI sessions from supervisor |
| Traces | No seq-ordered event stream from journal |
| Stop | No abort wired through BFF |

**UI surfaces that depend on D4**

| UI | Need |
|----|------|
| Harness **Test** chat | Create session → POST message → SSE → Abort |
| **Sessions** | List/get by tenant; open prior session; continue with `command_id` |
| **Traces** | Replay + live SSE (`seq`, `type`, tool/compaction pairs) |
| **Stop** | `POST …/abort` while turn is busy |
| (Optional) Fork | Branch at `at_seq` for “retry from here” |

Frontend mapping note (`frontend/contracts/README.md`): UI “Runs” → `/v1/sessions`; SSE → `GET /v1/sessions/{id}/events`.

## 2. Architecture rules (freeze)

1. **Browser never calls supervisor** — only the system BFF (D1).  
2. **Session create sends stored D3 pins only** — no free-form `harness_version` / digests from the client.  
3. **Same ready gate as Run** — BFF refuses create/message when `!run_allowed` (D2).  
4. **Journal is source of truth** — SSE may carry ephemeral chunks live-only; durable types persist.  
5. **`tool_start` before tool body** — unpaired start = unknown outcome (`AGENT_CONTRACT.md`).  
6. **`command_id` is required** on message POST — retries return the stored accept, not a second send.  
7. **SSE resume = `Last-Event-ID` = journal `seq`** — subscribe live *before* replay; skip `seq <= cursor`.  
8. **Abort ≠ terminate** — abort cancels in-flight turn; `DELETE` terminates the session.  
9. **Multi-replica sticky / shared live hub is out of D4** — track as D12; full industry checklist: [`SESSION-AT-SCALE.md`](./SESSION-AT-SCALE.md).  
10. **Drain fail-closed** — while draining: no new sessions; mutating turn APIs must also refuse (see gaps).

## 3. What exists today (AI / supervisor)

Evidence root: `services/supervisor/src/supervisor/`.

### 3.1 Session HTTP API — real

Router: `api/sessions.py` (`prefix="/v1/sessions"`).

| Verb | Path | Behavior | Status codes (high level) |
|------|------|----------|---------------------------|
| `POST` | `/v1/sessions` | Create; pin harness + optional composition | `201`; `503` draining / incompatible; `409` not offered; `429` quota |
| `GET` | `/v1/sessions` | List for tenant | `200` |
| `GET` | `/v1/sessions/{id}` | Detail + optional `is_busy` from runtime | `200` / `404` |
| `POST` | `/v1/sessions/{id}/messages` | Accept turn; **`command_id` dedup** | `202`; `404`/`409` recovery/terminated/approval; `429` budget |
| `POST` | `/v1/sessions/{id}/abort` | Cancel in-flight runtime work | `200` `{"status":"ok"}` |
| `POST` | `/v1/sessions/{id}/fork` | Copy journal prefix → new session | `201`; optional `at_seq` |
| `DELETE` | `/v1/sessions/{id}` | Terminate runtime + sandbox; status `terminated` | `204` |

Request/response shapes (`api/schemas.py`):

```text
CreateSessionRequest:  harness_version, runtime="echo",
                       composition_id?, composition_digest?
CreateSessionResponse: session_id, harness_version, runtime, status="active"
PostMessageRequest:    text, command_id
PostMessageResponse:   turn_id, status="accepted"
SessionSummary/Detail: session_id, status, harness_version, runtime,
                       last_seq, title?, message_count[, is_busy?]
ForkSessionRequest:    at_seq?
WireEvent:             seq, event_id, turn_id?, type, ts_ms, data
```

Tenant gate: `api/deps.py` `require_session_access` → 404 on miss/mismatch. Auth today is still the D1 stub (static bearer + tenant header).

### 3.2 SSE / events — real (single-process live)

Router: `api/events.py` — `GET /v1/sessions/{session_id}/events`.

| Property | Implementation |
|----------|----------------|
| Media type | `text/event-stream` |
| Resume | `Last-Event-ID` → integer journal `seq` (else from scratch) |
| Handover | **Subscribe live before journal replay**; skip live `seq <= cursor` |
| Wire shape | `WireEvent` via `api/wire.py` (`envelope_to_wire`) |
| Heartbeat | SSE comment ping; `_HEARTBEAT_SECS = 20.0` |
| Backpressure | Per-sub queue; slow client dropped; session continues |
| Disconnect | Client drop does **not** abort the session |

Live fan-out: `session/live.py` — `LiveHub` / `LiveSubscription`.

### 3.3 Journal — real

| Piece | Path | Role |
|-------|------|------|
| Writer | `journal/writer.py` | Allocates `seq` (never trusts the runtime); durable commit before return; blob offload for large payloads |
| Reader | `journal/reader.py` | Replay since cursor; unpaired tool/compaction/subagent helpers; latest history from last run-end |
| Commands | `journal/commands.py` | Durable HTTP `command_id` → stored accept body |
| Serde | `journal/serde.py` | Encode/decode agent events |
| Sync | `journal/sync.py` | History reconcile stub (`NotImplementedError`) |
| Schema | migrations `0001_journal`, `0002_commands` | `sessions`, `events`, `session_index` (`total_cost`, `message_count`, …), `commands` |

Fan-out (`session/manager.py`): runtime event → **append journal** → **publish LiveHub** → optional OTLP projector → guards/budget.

### 3.4 Statuses & lifecycle

Session `status` values used in manager:

| Status | How you get there |
|--------|-------------------|
| `active` | create / resume from `paused` |
| `paused` | idle reap (sticky) or deploy drain |
| `terminated` | `DELETE` / terminate |
| `failed` | recovery decision failed |
| `awaiting_approval` | approval required |
| `budget_exceeded` | budget abort path (checked on send) |

**Internal** `resume()` / idle reap / `drain()` exist on the manager/lifecycle helpers. **No** public `POST …/pause` or `POST …/resume` routes.

Modes: sticky vs stateless-per-turn (`session/modes.py`) — drain/reap pause sticky; terminate or stop-per-turn for stateless.

### 3.5 Idempotency — `command_id`

Message path (`api/sessions.py`):

1. `commands.get(session_id, command_id)` → if hit, return stored `202` body (no second send).  
2. `manager.ensure_ready` **before** claim (blocked recovery must not poison dedup).  
3. `commands.claim` → insert; on conflict return stored.  
4. `manager.send(..., command_id=...)`.

DB: `commands(session_id, command_id)` PK; survives process restart (`migrations/versions/0002_commands.py`).

**`contracts/githi_events.md`** — Githi extensions: compaction pair, skill invoked, ephemeral message chunks (**not** journaled), memory recall, session branch; pairing/orphan rules; priority bands.

Canonical supervisor vocabulary: `agent/events.py` (`Usage` includes `cost_total`; `MessageEnd`, `ToolStart`/`ToolEnd`, compaction/subagent/job types, `Envelope`).

## 5. Acceptance criteria (D4 — AI side)

Focus: supervisor + contracts + tests. System BFF/UI can lag slightly but AI must be BFF-ready.

### A. Session API correctness

- [ ] Create with D3-shaped body (`harness_version` + composition digest when required) returns `201` and `active`.  
- [ ] List/get are tenant-scoped (cross-tenant → `404`).

- [ ] Abort returns ok and yields abort/turn-end (or equivalent) in journal.  
- [ ] Terminate idempotent; further messages fail closed.  
- [ ] Fork returns new id; original prefix unchanged; child has copied seq history.

- [ ] Client disconnect does not abort.  
- [ ] Heartbeats on idle (~20s).  
- [ ] Critical pairs present for tool/compaction when those paths run (`tool_start` before side effects).

1. **Freeze wire doc** — table of routes + `WireEvent` + status enum (this doc + OpenAPI).

## 8. Target design (system ↔ AI)

```text
Browser
  │ user JWT
  ▼
System BFF
  ├─ D2 run_allowed?
  ├─ D3 load pins for harness.id
  ├─ ownership index (user_id, harness_id, ai_session_id, pin snapshot)
  ├─ mint command_id (client or BFF)
  └─ AiClient (D1 service auth)
        │
        ├─ POST /v1/sessions { harness_version, runtime, composition_* }
        ├─ POST /v1/sessions/{id}/messages { text, command_id }
        ├─ GET  /v1/sessions/{id}/events  (Last-Event-ID)
        ├─ POST /v1/sessions/{id}/abort
        └─ DELETE /v1/sessions/{id}
```

### 8.1 Ownership index (required)

AI `GET /v1/sessions` is **tenant**-scoped. System must keep:

```text
session_links
  ai_session_id (unique)
  user_id
  harness_id                 # product UUID
  tenant_id / principal_id   # minted at create (D1)
  harness_version, composition_digest  # pin snapshot
  status_cache?              # optional denorm for list UX
  created_at, ended_at?
```

Rules: list/get/message/SSE/delete authorize via this index (IDOR → **404**). Browser never supplies `ai_session_id` without membership. Create is the only insert path (after AI 201).

### 8.2 Product ↔ AI control mapping

| FE today | AI HTTP | BFF policy |
|----------|---------|------------|
| `POST …/pause` | Internal only | Unsupported / `501` until AI exposes — **no fake 200** |
| `POST …/resume` | Internal `resume()` | Same |
| `POST …/stop` (Test Stop) | `POST …/abort` | Stop generation = abort |
| End session / DELETE | `DELETE …` terminate | End session = terminate |
| `message_id` | `turn_id` | Alias or change FE to SSE-first |

Status map (suggested):

| AI | Product FE |
|----|------------|
| `active` (+ busy) | `running` |
| `paused` | `paused` |
| `terminated` | `completed` or `stopped` (pick one) |
| `failed` / `budget_exceeded` | `failed` |
| `awaiting_approval` | extend enum or map to `paused` + reason |

### 8.3 WireEvent → UI traces / tool chips

Browser consumes **snake_case** WireEvent only (not journal PascalCase).

| UI concept | WireEvent `type` | Notes |
|------------|------------------|-------|
| Run / turn bounds | `run_start`, `run_end`, `turn_start`, `turn_end` | |
| Assistant text | `message_end` | Authoritative; `data.usage` has tokens/cost |
| Tool chip open | `tool_start` | Pair on `tool_call_id`; args in `data` |
| Tool chip close | `tool_end` | `result`, `is_error`; duration ≈ Δ `ts_ms` |
| Error | `error` | |
| Idle checkpoint | `settled` | Turn done ≠ run done |
