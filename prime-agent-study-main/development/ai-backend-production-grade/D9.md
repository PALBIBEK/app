**Status:** PASS (2026-08-31) — verify cycle 0; 20/20; next orchestrator advance  
**Wave:** 3–4 (after D1 auth, D4 sessions, D6 file tools on TreeIO; grants depth in D11; sandbox isolation in D10)

**Goal:** Agent `/workspace` is a **hot cache**. Durable truth is Postgres path metadata + object-store bytes. Hydrate on session start, sync on dirty mutate/end. Staging uses Seaweed (or S3) + Postgres — not process memory. Optional control-plane file API + BFF for humans — never serve SoT from the sandbox FS.

**Done means (north star):**

> A scoped session survives supervisor restart with the same files. Compose Seaweed env is actually consumed. `WORKSPACE_STORE=postgres` + `OBJECT_STORAGE=seaweed` work through bootstrap. CAS sync fails closed. Product (or API) can list/get/put files against durable SoT under grants. Outer “tenant workspace” chrome is not confused with agent file trees.

## 1. Why D9 exists

D6 can read/write the sandbox tree. Without D9, files die with the process and compose object storage is dead config:

```text
Journal (Postgres events)     = SoT for turns / tools / run lifecycle
Postgres workspace_files      = SoT for path → blob pointers + version   ← missing runtime
Object store (S3/Seaweed/GCS) = SoT for immutable file bytes             ← adapter real; bootstrap unused
Sandbox /workspace            = hot cache only

Session create (+ scope_id)
  → authorize hydrate (workspace:read)
  → clear tree → pull blobs → verify sha
  → tools write/edit → mark_dirty
  → RunEnd / terminate → authorize sync (workspace:write) → CAS commit
```

Until D9 closes:

## 2. Architecture rules (freeze)

1. **Dual-SoT** (`contracts/workspace_dual_sot.md`) — journal ≠ file bodies; Postgres = path metadata; object store = bytes; sandbox = cache.  
2. **Do not event-source file bytes into the journal** — claim-check only (`file_id`, `path`, `content_sha256`, `version`).  
3. **Authz is control-plane** — `workspace:read` before hydrate, `workspace:write` before sync; sandbox process never decides grants (D11).  
4. **Hydrator has no GrantStore** — `SessionWorkspaceService` / `authorized_*` gate; `StoreWorkspaceHydrator` is mutex + store only.  
5. **CAS sync, fail closed** — no last-writer-wins; conflicts reported; durable wins + re-hydrate is the recovery policy (automate in D9).  
6. **Checksum verify on hydrate** — mismatch → hard fail (`ChecksumMismatch` / R11).  
7. **Mid-hydrate failure** → `HydrateIncomplete` (R8); tools gated until ready.  
8. **Path confinement in cache** — `LocalFsTreeIO` rejects `..` and symlink escape (R12); defense-in-depth, not authz.  
9. **Content-addressed keys** — `blobs/{sha256[0:2]}/{sha256}`.  
10. **Soft delete** — `deleted_at`; live uniqueness is partial unique among non-deleted rows.  
11. **MVP: one writer per scope** — no multi-writer lease yet.  
12. **Browser never reads sandbox FS** — BFF → supervisor Workspace API → durable store (D1).  
13. **Outer tenant `workspaceStore` ≠ agent `/workspace`** — different product nouns; do not merge.  
14. **Sandbox isolation (Docker/E2B/network)** is **D10** — D9 only requires a `WorkspaceTreeIO` adapter so hydrate/sync can run.

```18:30:services/supervisor/src/supervisor/seams/providers/workspace_store_factory.py
def create_workspace_store(
    name: str | None = None,
    *,
    objects: ObjectStorage | None = None,
) -> WorkspaceStore:
    """Select store from ``WORKSPACE_STORE`` or explicit name.

    Names: ``memory`` (default). Postgres adapter is WP-M3+/M4.
    """
    chosen = (name or os.environ.get("WORKSPACE_STORE") or "memory").strip().lower()
    if chosen == "memory":
        return MemoryWorkspaceStore(objects=objects or MemoryObjectStorage())
    raise ValueError(f"unknown WORKSPACE_STORE={chosen!r}")
```

### Path safety (cache)

```13:27:services/supervisor/src/supervisor/sandbox/workspace_tree.py
def _safe_rel(path: str) -> str:
    raw = path.strip().replace("\\", "/")
    if raw.startswith("/"):
        raw = raw[1:]
    parts: list[str] = []
    for part in raw.split("/"):
        if part in ("", "."):
            continue
        if part == "..":
            raise WorkspacePathEscape(path)
        parts.append(part)
    if not parts:
        raise WorkspacePathEscape(path)
    return "/".join(parts)
```
